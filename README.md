# platform-oms

CDK + Lambda APIs for catalog products and orders (OMS). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/platform-oms-archive`.

## What was built (EN)

`src/catalogs-products-handler` and `src/catalogs-orders-handler`. Hosted-zone choice uses `CDK_DEV_ACCOUNT`. Generated `cdk.context.json` (hosted-zone id + AWS account) was **removed**. No contract deployments.

## Qué se construyó (ES)

APIs de productos y pedidos. Contexto CDK de AWS eliminado.
